# mcpapps_bridge

This package is **not** versioned independently and has no changesets-managed changelog
(unlike the npm packages under `packages/*`) — it tracks the `mcpapps` CLI's release tag
(`v<cli-version>`) instead. See the [README](./README.md#versioning) for how a scaffolded
app resolves its dependency, and [`packages/cli/CHANGELOG.md`](../cli/CHANGELOG.md) for
the release history the `v<cli-version>` git tag it's pinned to actually corresponds to.
